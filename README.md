# RPG謎解き

このリポジトリは、謎解きゲームのプロジェクトです。

## 概要

RPG形式の謎解きゲームで、プレイヤーが出題される問題に答えていくゲームです。

## 遊び方

1. `README.html` をブラウザで開く
2. 出題される問題に答えを入力する
3. 「答える」ボタンをクリックして答えを確認する

## ファイル構成

- `README.html` - ゲームのメインUI
- `main.js` - ゲームのロジック

## 使い方

リポジトリをクローンした後、`README.html` をブラウザで開いてゲームをプレイしてください。

```bash
git clone https://github.com/nukko1103/RPG.git
cd RPG
# README.html をブラウザで開く
```
